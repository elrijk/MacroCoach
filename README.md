# MacroCoach

Ready-made macros for **WoW Forever** that explain themselves. Pick a macro,
read in plain words what it does, press Add, and drop it on your action bar.

## What it does

- **294 macros** for all 9 classes plus general ones. Spells are stored by ID, so every macro works in any client language.
- **Why macros?** A short intro with before/after pictures made from your own class spells.
- **Recommended**: 6-8 starter macros for your class, each with the problem it solves and when to press it.
- **Explain**: any macro broken down line by line in plain words.
- **Builder**: make your own macro from drop-down lists instead of an empty text box. Text mode can translate English spell names to your client's language.
- **Check**: finds old spell ranks on your bars and replaces them, flags typos, unknown spells and things removed in WoW Forever.
- **Share**: export your macros as a text code and import someone else's.
- **Safe**: never overwrites your own macro with the same name without asking; anything that cannot be done in combat waits until combat ends.

## Commands

`/coach` opens the window. `/coach commands` lists the rest. There is also a
"Ready-made macros" tab on the side of the game's `/macro` window.

## Languages

English and Russian are written by hand. German, French, Spanish, Italian,
Portuguese, Korean and Chinese are machine-translated: if a line reads wrong,
please open an issue with the correct text.

# MacroCoach (по-русски)

Готовые макросы для **WoW Forever**, которые объясняют сами себя.

- **294 макроса** для всех 9 классов и общие. Заклинания записаны по ID: макрос работает на любом языке клиента.
- **Зачем макросы**: короткое знакомство с картинками «было → стало» из заклинаний твоего класса.
- **Рекомендации**: 6-8 макросов для старта и зачем каждый.
- **Объяснение** любого макроса по строкам простыми словами.
- **Конструктор** своих макросов из списков; перевод английских названий заклинаний.
- **Проверка**: старые ранги на панелях, опечатки, невыученное, убранное в Forever.
- **Импорт и экспорт** своих макросов кодом.

Команда: `/coach` или `/макросы`.
