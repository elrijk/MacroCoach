# Sources

MacroCoach's code is MIT-licensed (see `LICENSE`).

Macros in `Data.lua` are stored by spell ID, so the game fills in spell names
in the client's language. Common macro patterns (mouseover casts, focus macros,
stance and form switches) are community knowledge; these public guides were
used as references when choosing which macros to include:

- rankedboost.com, WoW Forever Macros
- kami-labs.fr, Macros WoW Forever
- warcraft.wiki.gg, Useful macros
- zockify.com, Classic macros
